For one free-slot notice, recheck the current slot and Ready Pool. If the work is still eligible, use the existing supported PM assignment path exactly once; otherwise return one typed blocker. Do not create a new route, reservation, receipt, capability, or assignment authority, and do not retry an uncertain operation. Never perform pane, release, clear, checkout, label, workflow, or Slack effects from this instruction surface.
